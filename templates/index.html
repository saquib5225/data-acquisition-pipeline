Project Overview

This web app displays data from an end-to-end CS:GO Major Championships data pipeline. The system:

  • Scrapes tournament data from Wikipedia
  • Cleans and transforms the raw data
  • Loads it into a SQLite database
  • Displays data via a Flask web interface
