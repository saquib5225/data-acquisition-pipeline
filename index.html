CS:GO Major Championships Data Pipeline

1. Project Overview

This project implements an end-to-end data acquisition and preprocessing pipeline hosted on a Google Cloud Platform (GCP) Virtual Machine. The system scrapes tournament data for CS:GO Major Championships from Wikipedia, cleans and transforms the data, and loads it into a SQLite database.

2. Technologies Used

  • Google Cloud Platform VM
  • Python (Requests, BeautifulSoup, Pandas)
  • SQLite Database
  • Git + GitHub
  • Pytest (Unit + Integration Tests)

3. Pipeline Components

Scraper: Extracts tournament data from Wikipedia.

Transformer: Cleans and standardizes the data.

Loader: Stores cleaned data into SQLite.

Orchestrator: Runs the full pipeline automatically.
